# Garmin Uzbekistan — Interactive Mobile Web App for Instagram Profile

Interactive, mobile-first web application designed specifically for Garmin Uzbekistan's Instagram business profile bio link (`@garmin_uzbekistan`).

## 🌟 Key Features

1. **Interactive "Find Your Garmin" Smart Quiz**: 3-step recommendation engine guiding users to their ideal Garmin model based on sport, features, and budget.
2. **Interactive Flagship Comparison Tool**: Side-by-side spec comparator (fēnix 8, Forerunner 970, Instinct 3, Epix Pro, Venu 3) with price, display, battery, and GPS.
3. **Interactive Battery & Solar Simulator**: Dynamic sliders for daily sunlight and GPS training hours calculating realistic battery runtime across models.
4. **Full Filterable Catalog**: Complete 56-device official catalog synced with Garmin Uzbekistan database.
5. **1-Tap Direct Ordering via Telegram**: Pre-filled formatted order messages with product name and price in UZS.
6. **Showroom Locator**: Garmin Abay and Garmin Minor showrooms with 1-tap Yandex Maps & Google Maps navigation.
7. **Multi-Language Support**: Instant language switching between Russian (RU), Uzbek (UZ), and English (EN).
8. **Instagram Story Highlights Bar**: Animated story viewer modal.

## 🚀 How to Run Locally

You can preview the project with any local HTTP server:

```bash
# Using npx serve:
npx serve .

# Or using Python:
python -m http.server 8080
```

Open `http://localhost:8080` or the URL provided in your browser.

## 🌐 Deploying for Instagram Bio

You can deploy this project for free to:
- **Vercel**: `npx vercel`
- **Netlify**: Drag and drop the folder to Netlify Drop
- **GitHub Pages**: Push repository and enable GitHub Pages in repo settings

Add the resulting URL (or your custom domain `bio.garmin.com.uz`) to your Instagram business profile link!
